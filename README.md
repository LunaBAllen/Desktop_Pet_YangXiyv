## 简介

这是叶旸制作的化学元素拟人oc桌宠。
请勿换头当做自家oc/代餐。

———————————————————————

解压密码请见Read Me.txt。
压缩包解压后文件夹内会有两个文件，分别是桌宠_xxx（角色名）.exe与ReadMe.txt。

双击exe文件桌宠即可运行。首次运行时文件夹内将自动生成几个新文件并于桌面创建桌宠的快捷方式。

其他文件不用管，也请不要打开或修改，否则桌宠可能会使用异常；桌面快捷方式如果不需要可以删掉；
你需要找到同文件夹下名为api_key.json的文件，使用记事本模式打开，然后继续阅读这份文档并按照提示操作。

桌宠实现对话功能需要接入一个deepseek api。

配布件中不包含api key，还请自行于https://platform.deepseek.com获取。
获取教程请见https://api-docs.deepseek.com/zh-cn。

注意，api key属于敏感信息，获取之后请不要泄露至网络或分享给他人。

获取后打开api_key.json，将指定位置的英文双引号中的占位符(sk-在这里填入你的...)整段替换为你的个人api key。
注意不要保留中文占位符、不要将引号删去。修改之后保存文档并关闭，重启桌宠。

之后桌宠方可实现与你的智能对话。

## 启动问候/整点报时
在每天的不同时段间（早、中、晚、深夜）启动桌宠会有不同问候语，每日首次启动会有特殊问候语（仅限早晨）。

部分桌宠在特定时段内首次启动会有特殊问候语。

当前时间为整点时，桌宠将进行报时。


## 剪贴板检测

当检测到复制内容为错误报告时，桌宠将尝试捕获错误类型，并将错误原因与对应解决方法列出。

剪贴板内容识别方式为本地读取&处理，不会上传至云端，所以不会泄漏用户隐私，请放心。

（注：此功能制作初衷是作者太懒了不想看错误报告希望可以更快速得知错误类型与解决方法，故而仅将自己日常中会经常遇到的错误类型加入了检测列表中，所以会有很多错误将无法被识别。）


## 日程＆提醒

右键点击桌宠打开菜单，点击日程提醒功能，写入日程。

桌宠将于设定时间结束后提醒用户完成日程。

## 管家功能

右键点击桌宠打开菜单，点击管家功能，将程序名(名称中可以不包含.exe)与对应文件路径(精确到程序路径)分别填入指定位置即可。
（路径示例：C:\Program Files\ExampleApp\example.exe）

此后你可以于此菜单下点击你已添加的程序以启动该程序。

添加程序时请确保你所添加的程序是安全、你所信任的。桌宠无法确保你的程序没有病毒。
